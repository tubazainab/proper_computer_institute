How to Run in XAMPP (Windows)

The complete PHP/MySQL codebase with prepared statements and 21 database tables is ready in this directory.

Step 1: Copy Project Folder to XAMPP
C:\xampp\htdocs\Proper Computer
Step 2: Start Apache and MySQL in XAMPP Control Panel

Open XAMPP Control Panel and click "Start" next to Apache and MySQL.

Step 3: Run 1-Click Database Installer

Visit in your browser:

http://localhost/Proper%20Computer/install.php

Click "Run 1-Click Database Setup & Seeder". It will automatically build the MySQL database, create 21 tables, and insert all 65+ courses, sample students, admissions, and targets.
